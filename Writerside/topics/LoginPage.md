# Login page

![Login Page](loginpage.jpg)

"Email" will be set when administrators of the buildbase application [create a new user](#create-a-new-user).  
This email will act as authentication and [authorization](#role-management) for the person to log into the system.
The combination of email and password will be handed to the employee in person by the administrators.

The password will also be set by buildbase admins when they are [creating a new user](#create-a-new-user).  
This password can only be [changed](#change-password) by the administrators.

There will be an option to remember the user.  
This will make sure the user can open the application without the need to login again every time.
