# Werkroosters

## Werkrooster bewerken
### Dagplanning
<img src="WorksvheduleEditDayPlanning.png"  alt="Dagplanning"/>

#### Event toevoegen
<procedure>
    <step>
        Op het weekoverzicht, klik op het tijdstip waarop u een event wilt toevoegen.
        <img src="WorksvheduleEditDayPlanningHourHighlighted.png"  alt="Dagplanning tijdstip aangeduid"/>
    </step>
    <step>
        Indien nodig, pas de start- en eindtijd aan en klik op <shortcut>bevestig</shortcut>.
        <img src="WorksvheduleEditDayPlanningEventCreateConfirmHighlighted.png"  alt="Dagplanning event aanmaken bevestigen aangeduid"/>
    </step>
    <step>
        Het event staat nu voor u weergegeven op de dagplanning.
    </step>
    <step>
        Om de dagplanning op te slaan, klik op <shortcut>opslaan</shortcut>.
        <img src="WorksvheduleEditDayPlanningSaveHighlighted.png"  alt="Dagplanning opslaan aangeduid"/>
    </step>
</procedure>

#### Event aanpassen
<procedure>
    <step>
        Op het weekoverzicht, klik op het event dat u wilt aanpassen.
        <img src="WorksvheduleEditDayPlanningEventHighlighted.png"  alt="Dagplanning event aangeduid"/>
    </step>
    <step>
        Pas de start- en eindtijd aan en klik op <shortcut>bevestig</shortcut>.
        <img src="WorksvheduleEditDayPlanningEventEditConfirmHighlighted.png"  alt="Dagplanning wijzigen bevestigen aangeduid"/>
    </step>
    <step>
        Het event staat nu voor u weergegeven op de dagplanning.
    </step>
    <step>
        Om de wijziging op te slaan, klik op <shortcut>opslaan</shortcut>.
        <img src="WorksvheduleEditDayPlanningSaveHighlighted.png"  alt="Dagplanning opslaan aangeduid"/>
    </step>
</procedure>

#### Event verwijderen
<procedure>
    <step>
        Op het weekoverzicht, klik op het event dat u wilt verwijderen.
        <img src="WorksvheduleEditDayPlanningEventHighlighted.png"  alt="Dagplanning event aangeduid"/>
    </step>
    <step>
        Klik op het vuilbakje.
        <img src="WorksvheduleEditDayPlanningEventDeleteDeleteHighlighted.png"  alt="Dagplanning event werwijderen aangeduid"/>
    </step>
    <step>
        Het event is nu niet meer weergegeven op de dagplanning.
    </step>
    <step>
        Om de verwijdering op te slaan, klik op <shortcut>opslaan</shortcut>.
        <img src="WorkscheduleEditDayPlanningDeleteSaveHighlighted.png"  alt="Dagplanning opslaan aangeduid"/>
    </step>
</procedure>
