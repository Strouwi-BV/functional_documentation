# Consult hours

On the consult hours page the admin can consult hours for a given period of time.
When choosing the option 'show inactive options' the inactive employees, clients and projects will be visible in the dropdown menu's.
These will have no effect on the generated data.

## Consult hours of employees
The admin can consult the employees hours for a given period of time.
![Consult hours employees](Consult_hours_employees_data.png)

In the consult hours view the admin can select a specific employee or all employees. He can select the current month or choose a
specific start date and end date. When choosing 'show data' a table is generated with the clockings for the selected values.
When choosing 'export data' a file with this data is generated.


## Consult hours of clients and projects
When the module client and project management is installed the admin can consult hours for an
employee and for clients and projects. For consulting hours of employees see [Consult-hours-of-employees](#Consult-hours-of-employees)
![Consult hours clients](Consult_hours_clients_data.png)

By selecting the option clients the admin can generate reports for clients.
In the consult hours view the admin can select a specific client or all clients. When a specific client is chosen the admin can now select a specific
project or all the projects from that client.
The admin can select the current month or choose a specific start date and end date. When choosing 'show data' a table is generated with the clockings for the selected values.
When choosing 'export data' a file with this data is generated.
